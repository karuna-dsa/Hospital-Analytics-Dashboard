# 🏥 Hospital Analytics Dashboard

## 📌 Project Overview
This project focuses on analyzing hospital data to understand patient trends, hospital performance, healthcare services, and key operational metrics through an interactive Power BI dashboard.

## 🎯 Project Objectives
- Analyze patient and hospital performance.
- Monitor admission and discharge trends.
- Identify patterns in patient demographics.
- Evaluate hospital performance using KPIs.
- Generate actionable insights through data visualization.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📊 Dashboard Features
- Interactive KPI cards
- Patient analysis
- Admission and discharge analysis
- Hospital performance monitoring
- Dynamic filters and slicers

## 📁 Project Files
- Power BI dashboard (.pbix)
- Dataset
- Dashboard screenshots

## 💡 Key Insights
The dashboard provides insights into patient trends, hospital operations, and performance indicators to support data-driven decision-making.
